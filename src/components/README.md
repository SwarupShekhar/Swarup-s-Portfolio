Aetheris: The Systems Portfolio of Swarup Shekhar
Aetheris is a cinematic, multi-sensory digital experience that captures the intersection of market intelligence, product design, and technical orchestration. It serves as a live demonstration of a system-first mindset applied to digital products.

The platform is engineered with Next.js (App Router), TypeScript, and Framer Motion to transform a professional journey into a high-fidelity, scroll-driven narrative.

🌌 The Narrative Experience
Aetheris is structured as a five-scene odyssey that mirrors the product development lifecycle:

Scene 1: Identity : An introduction to the Analyst-Architect hybrid persona.

Scene 2: The Analyst : Showcasing deep-dive research capabilities and market insights derived from roles at Vaidik EduServices.

Scene 3: The Builder : Transitioning from data to code, focusing on the development of React Native and Next.js environments.

Scene 4: The Orchestrator : Highlighting the management of complex product ecosystems like Vibespark and WeHostt.

Scene 5: The Proof : A data-backed System Gallery providing tangible evidence of execution.

🛠️ Integrated Systems
The portfolio acts as a central hub for several active product ecosystems:

Vibespark : A React Native mobile application exploring social connectivity and human interaction.

WeHostt : A specialized platform facilitating VR services and hardware logistics.

VDesitutoring : An education-focused initiative aimed at scaling personalized learning environments.

Englivo : A project blending linguistic research with interactive digital tools.

⚙️ Technical Architecture
Core Stack
Framework : Next.js 14+ (App Router) for optimized routing and performance.

Language : TypeScript for robust, type-safe system logic.

Styling : Tailwind CSS for responsive, utility-first design.

Animation : Framer Motion for complex, physics-based motion transitions.

Performance Engineering
Dynamic Resource Allocation : Aetheris uses a custom GPU-detection layer. Heavy visual effects, including the Galaxy Field, Particle Halo, and Liquid Ether, are dynamically disabled on mobile devices to ensure a smooth 60fps experience regardless of hardware.
